# 🛍️ Alura Store Latam -- Análisis Estratégico de Ventas

## 📌 Descripción del Proyecto

Este proyecto realiza un análisis exploratorio de datos (EDA) sobre
cuatro tiendas de Alura Store Latam. El objetivo es determinar en cuál
tienda el Sr. Juan debería vender su negocio, considerando métricas
financieras, comerciales y de satisfacción del cliente.

------------------------------------------------------------------------

## 🎯 Objetivo del Negocio

Responder a la pregunta:

¿En cuál tienda debería vender el Sr. Juan considerando ingresos,
satisfacción del cliente y eficiencia operativa?

Se analizaron: - Ingresos totales - Ventas por categoría - Calificación
promedio - Productos más y menos vendidos - Costo de envío promedio

------------------------------------------------------------------------

### 🚚 Costo de Envío Promedio

------------------------------------------------------------------------

## 🏆 Conclusión

Se recomienda vender en **Tienda 3**, ya que presenta el mejor
equilibrio entre: - Alta calificación de clientes - Ingresos
competitivos - Fuerte posicionamiento en la categoría más vendida -
Costos logísticos eficientes
